# RECA Digital — изолированная витрина

Демонстрационный интерфейс вымышленной кофейни «Маяк», только фиктивные заказы. Никаких реальных персональных данных, оплат, API-ключей или backend.

## Запуск вручную

```bash
cd sandbox-app
npm install
npm run dev
```

Сборка: `npm run build`. Запуск выполняется только по решению разработчика; GitHub Actions для этого приложения пока не настроены.

## Рамки первой задачи Codex

Менять можно **только** `sandbox-app/src/App.jsx` и `sandbox-app/src/styles.css`. Задача — UX: заметный приоритет новых заказов, понятные статусы и улучшенное мобильное представление. Нельзя добавлять внешние сервисы, реальные данные, платежи, авторизацию или менять пакеты/скрипты/CI. Результат — Draft PR для человека, без автослияния и деплоя.

**Важно:** текущий платный controller AUTO-002 умеет только `docs/pilot.md`, поэтому эта UI-задача НЕ может быть отправлена ему без отдельной доработки Publisher и нового согласованного допуска. Не пытайтесь переиспользовать израсходованные receipt-теги AUTO-002.
