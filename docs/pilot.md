# Памятка кафе «Лаборатория»

## 1. Получение заказа
Принять запрос, уточнить детали и подтвердить состав заказа без лишних данных.

## 2. Приготовление
Передать заказ на кухню, собрать позиции по очереди и проверить готовность.

## 3. Выдача
Сверить заказ с заявкой, вежливо передать гостю и отметить завершение.
