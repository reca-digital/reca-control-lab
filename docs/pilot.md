# Синтетический пилот обмена заданиями

Это вымышленный демонстрационный документ. Он не содержит данных рабочего проекта.

## Issue

Issue фиксирует одну согласованную задачу, её ограничения и критерии приёмки.

## Draft PR

Draft PR показывает предложенное изменение и позволяет ознакомиться с ним без слияния в защищённую ветку.

## Ревью

Ревьюер читает изменение и оставляет замечание. Исполнитель может ответить отдельным исправлением в той же рабочей ветке.

## Повторное исправление

После одного исправления пилот останавливается и не вызывает автоматические новые задачи.

## Границы пилота

Нет автоматического запуска, работы с секретами, платных API, деплоя и доступа к приватному коду.
